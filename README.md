# Night Fleet

A dark, red space-opera theme for Claude Code in the Claude desktop app.

Behind your chat, a hooded dark warlord with a humming red blade stands on a red-lit deck,
silhouetted against a dying red planet. A black capital ship drifts overhead firing red bolts,
fighter squadrons chase each other across the screen, and distant explosions and lightspeed
jumps flicker in the nebula. The app's colors switch to deep black with a crimson accent.

All the art is original.

## Install

At the prompt of a Claude Code terminal session:

```
/plugin install nightfleet --marketplace housemoneyproperties-create/nightfleet-theme
```

Answer `y` to add the marketplace, then pick a scope (user is first).

From a shell:

```bash
claude plugin install nightfleet --marketplace housemoneyproperties-create/nightfleet-theme
```

In the desktop app, where `/plugin` does not run: click + next to the prompt box, then Plugins,
Add marketplace with `housemoneyproperties-create/nightfleet-theme`, then Add plugin.

## Notes

- The theme draws in local sessions of the Claude desktop app (and the mobile app), not in the terminal.
- On a Mac, turn off **System Settings → Accessibility → Display → Reduce transparency**.
  With it on, the app makes its panels solid and the background stays hidden (the colors still change).
- Only one theme shows at a time, so disable any other theme mod you have on.
- The scene respects Reduce motion: with it on, the animation stops.

## Changing the scene

`hooks/scene.ts` is generated by `tools/gen_fleet.py`:

```bash
python3 tools/gen_fleet.py /tmp hooks/scene.ts
```
